# Changelog

All notable changes to the public Chronos release line are documented here.

## [1.0] - 2026-11-03

First public baseline release. This release consolidates the complete Chronos application and its previously validated feature set.

- Multiple named floating countdown timers with optional notes.
- Always-on-top timer windows, independent from the main dashboard.
- Compact mode, individual resizing, responsive content scaling, and adjustable transparency.
- Repeating WAV alarm, sound test, visual flashing, and alarm acknowledgement.
- Pause, resume, reset, add-one-minute, and individual timer deletion controls.
- Persistent creation history with individual and clear-all deletion.
- Native Windows notification-area icon with a custom Chronos dark/neon menu.
- Spanish/English interface selection in Settings, persisted between launches; changing language refreshes the dashboard and open timer windows without resetting timer state.
- Single-instance protection and local persistence of timers, preferences, history, and logs.
- Windows build scripts using PyInstaller in `onedir` mode.
- Bilingual English and Spanish documentation and Apache License 2.0 attribution notices.

Chronos 1.0 is the canonical public starting point for subsequent development. Earlier numbered packages were development iterations and are superseded by this baseline.
