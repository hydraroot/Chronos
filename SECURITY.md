# Security policy

## Supported version

Chronos 1.0 is the public baseline. Security-related fixes should be developed against the current supported release or its successor.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting / Security Advisories for this repository when available. If private reporting is not enabled, open an issue without publishing secrets, personal data, or a weaponizable proof of concept; ask the maintainer to move the discussion to a private channel.

Do not include passwords, signing API tokens, certificates, private keys, or personal identity documents in reports.
