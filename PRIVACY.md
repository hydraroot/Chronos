# Privacy policy / Política de privacidad

**Chronos 1.0 — WDS657**

## English

Chronos is a local Windows desktop application. It does not require an account, does not include analytics or telemetry, and the application code does not send timer titles, notes, history, settings, logs, or other user data to a remote service.

User data is stored locally in `%APPDATA%\Chronos\`. The application uses local Windows APIs, Tkinter, Pillow for local image handling, and WAV playback. Network access may be used by the user to download the source, install Python packages, or obtain build tools; those actions are separate from normal Chronos operation.

**This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.**

To uninstall the portable build, exit Chronos from its system-tray menu and delete the folder containing `Chronos.exe` and `_internal`. To remove personal data as well, separately delete `%APPDATA%\Chronos\`. This also removes saved timers, history, settings, and logs.

## Español

Chronos es una aplicación de escritorio local para Windows. No requiere una cuenta, no incluye analítica ni telemetría y el código de la aplicación no envía títulos de temporizadores, notas, historial, ajustes, registros ni otros datos del usuario a servicios remotos.

Los datos se guardan localmente en `%APPDATA%\Chronos\`. La aplicación utiliza APIs locales de Windows, Tkinter, Pillow para procesar imágenes locales y reproducción de archivos WAV. El usuario puede necesitar conexión a Internet para descargar el código, instalar paquetes de Python u obtener herramientas de compilación; esas acciones son independientes del funcionamiento normal de Chronos.

**Este programa no transferirá información a otros sistemas conectados en red salvo que el usuario o la persona que lo instale u opere lo solicite específicamente.**

Para desinstalar la versión portable, salí de Chronos desde el menú de la bandeja del sistema y eliminá la carpeta que contiene `Chronos.exe` y `_internal`. Para borrar también los datos personales, eliminá por separado `%APPDATA%\Chronos\`. Esto borra temporizadores guardados, historial, ajustes y registros.
