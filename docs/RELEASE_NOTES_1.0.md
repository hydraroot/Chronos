# Chronos 1.0 — First public baseline

Chronos is a floating multi-timer for Windows 10 and Windows 11. This release establishes the public baseline for future development.

## Download

- `Chronos-1.0-Windows-x64-unsigned.zip` — portable Windows x64 build. Extract the ZIP and run `Chronos.exe` from the `Chronos` folder. Keep `_internal` and all companion files together.

## Important signing status

This initial release is **unsigned**. Chronos has not yet been approved for the SignPath Foundation open-source signing program. See the [Code signing policy](https://github.com/hydraroot/Chronos/blob/main/CODE_SIGNING_POLICY.md). Do not treat this artifact as publisher-verified.
