# Contributing to Chronos 1.0

Thanks for your interest in Chronos. Bug reports, ideas, and pull requests are welcome. Chronos 1.0 is the canonical public baseline for the project.

## Before opening an issue

- Check whether the issue has already been reported.
- Include your Windows edition/build and display scaling when reporting UI problems.
- If running from source, include your Python version.
- Describe the exact steps to reproduce the issue.
- Include relevant lines from `%APPDATA%\Chronos\chronos.log`, after removing any personal information.

## Pull requests

- Base changes on the official Chronos 1.0 source or a clearly identified later official release.
- Keep changes focused and explain the reason for each user-visible change.
- Test timer creation, pause/resume, alarm acknowledgement, collapse/expand, resizing, system-tray behavior, and single-instance behavior when relevant.
- Update both `README.md` and `README.es.md` when user-facing behavior or instructions change.
- Update `CHANGELOG.md`.
- Mark modified files as changed and retain the original project attribution and `NOTICE` file.
